🎤 „Hey Gustav" einrichten (iOS 18+)

Mit Vocal Shortcuts sagst du „Hey Gustav" statt „Hey Siri":

  1. Einstellungen → Bedienungshilfen → Vocal Shortcuts
  2. Vocal Shortcuts einrichten tippen
  3. Siri auswählen (nicht „Siri Request")
  4. Als Phrase Hey Gustav eingeben
  5. Die Phrase 3× laut sprechen
  6. Fertig! Danach: „Hey Gustav" … [kurz warten] … „Salat gießen"

Kurzbefehle importieren

  1. Kurzbefehl importieren (grüner Button unten)
  2. In der Kurzbefehle-App: oben rechts „Hinzufügen"
  3. Testen: „Hey Gustav, Salat gießen"

Alle auf einmal (Mac)

Terminal öffnen und alle Kurzbefehle importieren:

open ~/Downloads/*.shortcut

Android – HTTP Shortcuts App

  1. App HTTP Shortcuts installieren (kostenlos)
  2. Menü → Import / Export → Import from cURL
  3. cURL-Datei von unten öffnen/kopieren → Shortcut speichern
  4. Widget auf Startbildschirm legen

Google Assistant Routine (optional)

  1. Google Home App → Routinen
  2. Neue Routine mit Sprachbefehl Salat gießen
  3. Aktion: URL öffnen oder HTTP Shortcut starten
  4. Dann: „Hey Google, Salat gießen"
